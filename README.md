# Бронь Сервис · Landing skill experiment

Отдельная экспериментальная версия лендинга франшизы. **Существующий репозиторий `bronservis51-bot/bronservice-franchise` не изменялся.**

## Сайт
https://bronservis51-bot.github.io/bronservice-landing-skill/

Статический сайт без сборки, пакетов и платных сервисов. Для локального просмотра: `python3 -m http.server 8000` из папки проекта.

## Дизайн
- Основа: [landing-page-design](https://github.com/elayadesign/ai-design-skills/blob/a2735a3eaf092eaaffb6dc17df25de33ef3bd048/skills/landing-page-design/SKILL.md), полный текст сохранён в AGENTS.md.
- Брендбук имеет приоритет: Montserrat, чёрный, белый и серебристый; фирменный логотип без перерисовки.
- Крупная типографика, фиксированная плавающая навигация, короткая история, анимация фразы при прокрутке.
- Исходные логотип и фотографии скопированы из текущего публичного сайта в assets/, ссылки на основной сайт для загрузки ресурсов не используются.
- Информация о сети, вложениях и взносе взята из текущей публичной страницы компании на 26.10.2026. Гарантия 45 дней — из условий компании. Нет выдуманных отзывов или гарантии доходности.

## Заявки и конфиденциальность
Анкета готовит сообщение и показывает его посетителю. Только при явном нажатии открывает WhatsApp действующего контакта франшизы +7 995 666 66 14. Пользователь отправляет сообщение самостоятельно. Рабочая Supabase, CRM и API существующего лендинга не подключены. Данные анкеты не сохраняются, аналитики и cookie нет.

## Индексация
Концепция закрыта от индексации через robots.txt и meta robots, чтобы не конкурировать с основным лендингом. Это не ограничение доступа: GitHub Pages остаётся публичным.

## Проверки
Синтаксис JavaScript, локальные ссылки и ресурсы; визуальная проверка и интерактивные сценарии выполняются отдельно при публикации.

Фирменные изображения и логотип принадлежат их правообладателям. Лицензия исходного скилла: THIRD_PARTY_LICENSE.txt. В AGENTS.md сохранено также upstream уведомление об авторских правах taste-skill.

## Версия 02: материал и продукт
Первый экран переработан вокруг идеи «Тонкая защита. Большое дело». Два прозрачных предметных рендера созданы встроенным ImageGen. Их итоговые версии: assets/phone-peel-v2.png и assets/phone-flat-v2.png. Промпты описывают один графитовый смартфон с приподнятой плёнкой и тот же смартфон с полностью нанесённой плёнкой; монохром, прозрачный фон, студийный свет, без логотипов и интерфейса. Промпты сохранены в docs/image-prompts-v2.md.

Ползунок меняет прозрачность двух кадров; это художественная визуализация нанесения, не физический тест. На компьютере лёгкое движение телефона следует за указателем. При reduced motion движение отключено. Реальные фотографии сети вынесены в отдельный блок. Первая версия доступна в истории коммитов (1e9946b).
